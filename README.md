Задание
Сверстать одностраничный сайт-лендинг интернет-магазина мебели и предметов интерьера (B2C; название бренда и логотип — по макету, в макете «Furniutr.» — уточнить написание: «Furniutr.» / «Furnitur.») по макету. Страница одна: «Главная» (лендинг) из секций: шапка, hero, «About Furniture», «More value from this Furniture», «Product», «Let’s Try Now», футер. В макете отрисована только десктопная версия (фрейм «Desktop», ширина ~1440 px — уточнить); планшетная и мобильная версии в макете отсутствуют — адаптировать самостоятельно в стилистике макета (уточнить, нужна ли адаптивность и будут ли дорисованы мобильные макеты); промежуточные ширины — резиново, без горизонтального скролла. Пункты меню ведут к секциям страницы (якорные ссылки) — уточнить, нужны ли отдельные страницы «About», «Collection», «Shop». Язык контента — английский, как в макете (уточнить, нужен ли перевод на русский).

Счётчик товаров у корзины в макете отсутствует — уточнить. Поведение поиска (раскрытие поля / поп-ап) — уточнить, в макете не отрисовано. Активный пункт меню и hover — уточнить (предлагается коралловый цвет). Фиксация шапки при прокрутке — уточнить.
Заголовки секций — двухуровневые: первая строка — тёмный гротеск, полужирный, обычным регистром («About», «More value from this», «Our you have to buy» — уточнить текст, вероятно опечатка); вторая строка — крупное слово контурным (outline) начертанием: тёмная обводка без заливки («Furniture», «Product», «Let’s»). Декор — фоновыми элементами / псевдоэлементами, не мешающими выделению текста и кликам.
